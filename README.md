# وبلاگ شخصی زتسو

قالب ایستای فارسی (RTL) با تم تیره‌ی مینیمال و فونت مدام، همراه با پنل مدیریت مارک‌داون.
بدون فریم‌ورک، بدون وابستگی خارجی، بدون مرحله‌ی build.

## اجرا

```bash
cd site
python3 -m http.server 8000
# سپس http://localhost:8000
```

باز کردن مستقیم `index.html` هم کار می‌کند.

## صفحه‌ها

| فایل | کاربرد |
| --- | --- |
| `index.html` | معرفی + رایت‌آپ‌ها |
| `post.html?id=...` | نمایش یک نوشته |
| `admin.html` | پنل مدیریت (نوشتن، ویرایش، جستجو، حذف، انتشار) |

پنل عمداً در منوی عمومی نیست؛ فقط با آدرس مستقیم باز می‌شود.

## چرخه‌ی نوشتن و انتشار (مهم)

داده‌ی سایت دو لایه دارد:

1. **`writeups.js`** — داده‌ی منتشرشده؛ همان چیزی که برای همه‌ی بازدیدکننده‌ها دیده می‌شود.
2. **پیش‌نویس مرورگر** — تغییراتی که توی پنل می‌دهی و هنوز منتشر نشده‌اند (فقط همان مرورگر می‌بیند).

مراحل کار:

1. در `admin.html` نوشته را بنویس (مستقیم یا با «بارگذاری فایل .md») و **ذخیره** کن.
2. دکمه‌ی **«انتشار روی سایت»** را بزن → فایل `writeups.js` دانلود می‌شود.
3. فایل دانلودشده را در پوشه‌ی سایت جایگزین کن (جای `writeups.js` قبلی).

تمام. از آن لحظه نوشته برای همه روی سایت است — روی هر مرورگر و هر دستگاهی.
این روش حتی اگر ذخیره‌سازی مرورگر کاملاً بسته باشد هم کار می‌کند.

## ساختار

```
site/
├─ index.html
├─ post.html
├─ admin.html
├─ writeups.js        ← داده‌ی منتشرشده (توسط پنل دانلود و جایگزین می‌شود)
└─ assets/
   ├─ css/
   │  ├─ tokens.css   ← فونت مدام، رنگ، فاصله
   │  ├─ style.css    ← کامپوننت‌های سایت
   │  └─ admin.css    ← فقط پنل
   ├─ js/
   │  ├─ config.js    ← نام، بیو، لینک‌ها
   │  ├─ store.js     ← لایه‌ی داده + زمان مطالعه‌ی خودکار
   │  ├─ markdown.js  ← مبدل مارک‌داون → HTML
   │  ├─ main.js      ← رندر صفحه‌ی اصلی
   │  ├─ post.js      ← رندر یک نوشته
   │  └─ admin.js     ← منطق پنل
   ├─ fonts/           ← مدام (۴۰۰ تا ۷۰۰)
   └─ img/             ← عکس پروفایل
```

## پشتیبان‌گیری

خود `writeups.js` پشتیبان دائمی سایت است؛ کپی از آن کافیست.
علاوه بر آن، دکمه‌های «گرفتن پشتیبان JSON» و «بازگرداندن پشتیبان» در پنل برای انتقال بین دستگاه‌ها هستند.

## شخصی‌سازی

- نام، بیو، لینک‌ها ← `assets/js/config.js`
- رنگ اکسنت ← `assets/css/tokens.css` (متغیر `--accent`)
